大工选课与培养方案导航 · 静态站点包
========================================

一、这是什么
------------
纯静态站点，4 个文件，无后端、无构建、无第三方依赖。
解压后 index.html 在根目录，直接上传到任意静态托管即可访问；
本地双击 index.html 也能离线运行。

数据规模：
- 专业目录 77 个（教务处 2025 年招生专业一览表）
- 培养方案 17 条，覆盖 10 个专业（机械 4 方向、软件 3 方向、智能制造 2、智能车辆 2 等）
- 全部方案已核对；数字来自结构化字段，不经模型生成

二、怎么上传
------------
GitHub Pages：
    把 4 个文件 + README.txt 推到仓库根目录，Settings → Pages 选分支根目录。

对象存储（阿里云 OSS / 腾讯 COS / 华为 OBS）：
    整目录上传，把 index.html 设为默认首页；静态网站托管开启即可。

Nginx：
    server {
        listen 80;
        root /var/www/dlut;
        index index.html;
    }

LearnBuddy / 其他平台：
    上传整个目录（保持 index.html 在根），无需 Node、无需构建命令。

三、检索与模型（可选）
----------------------
页面启动会探测同源 /api/health：
- 返回 {"ask_ready": true} → 自动走 /api/ask（服务端检索）
- 不存在或 2.5 秒超时 → 自动回退浏览器内本地匹配，页面照常可用

纯静态托管没有后端，会一直走本地匹配，这是预期行为，不影响演示。
不要在前端写 GLM Key；需要模型措辞时，由同源 /api/glm 代理转发。

四、文件说明
------------
index.html   页面骨架
styles.css   样式
app.js       检索匹配、四态渲染、远程接口与回退
data.js      数据（生成物，勿手改；改 data/*.json 后跑 tools/build_data.py）

五、不要做
----------
- 不要手改 data.js
- 不要把任何 API Key 写进前端
- 不要把 index.html 放进子目录后直接访问（相对路径会失效）
